# Gram
🚀 Gram — AI-Powered Business Language Learning Platform
Gram — это современная кроссплатформенная экосистема для сверхбыстрого освоения иностранных языков в сфере бизнеса, карьеры и международного менеджмента. Проект объединяет гибкость мобильной разработки и мощь веб-технологий, используя передовой стек (Expo, Next.js, TypeScript). В основе методологии лежит интеллектуальный анализ прогресса с помощью LLM-модели DeepSeek.
Приложение создано для предпринимателей, топ-менеджеров и специалистов, которым языковые навыки необходимы для решения реальных бизнес-задач: проведения переговоров, защиты презентаций, прохождения интервью и ведения деловой переписки без языкового барьера.
✨ Ключевые возможности (Core Features)
• 🗣️ Разговорные лаборатории (Speaking Labs): Интерактивные тренажеры для отработки устной речи в условиях реальных бизнес-кейсов (питчи, совещания, факап-менеджмент).
• 🤖 AI-Аналитика на базе DeepSeek: Интеграция с LLM нового поколения. Модель мгновенно сканирует выполненные домашние задания, эссе и аудиозаписи ответов. Пользователь получает детальный фидбек, разбор грамматических ошибок, оценку бизнес-тона (Tone of Voice) и рекомендации по улучшению профессиональной лексики.
• 📝 Умные конспекты (Smart Notes): Интерактивные выжимки по грамматике, правилам делового этикета и узкоспециализированному сленгу (FinTech, IT, Legal, Marketing).
• 🧪 Комплексное тестирование: Динамические тесты для оценки понимания контекста, идиом и корпоративной терминологии.
• 🏠 Практические домашние задания: Задания, имитирующие реальную рутину: от составления официальных писем (Cold Emails) до анализа контрактов.
🛠️ Технологический стек (Tech Stack)
Архитектура проекта спроектирована по принципу монорепозитория для эффективного переиспользования бизнес-логики и типов между платформами:
• Frontend (Mobile): Expo / React Native — кроссплатформенное мобильное приложение для iOS и Android с нативной производительностью.
• Frontend (Web) & Admin: Next.js — высокопроизводительное веб-приложение с поддержкой SSR для маркетинговых страниц и личного кабинета.
• Язык разработки: TypeScript — обеспечивает 100% покрытие типов, безопасность данных и масштабируемость кодовой базы.
• Искусственный Интеллект: DeepSeek API — используется в качестве ядра проверки текстового и аудио-контента, выполняя роль персонального AI-тьютора.
